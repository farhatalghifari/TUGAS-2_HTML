Tentang Coding Club

Coding Club merupakan kegiatan yang membantu siswa mempelajari dunia pemrograman dan teknologi.

Melalui Coding Club, siswa dapat meningkatkan kemampuan coding, bekerja sama dalam tim, dan membuat proyek sederhana.



Apa yang Dipelajari

  • HTML
  • CSS
  • JavaScript
  • Pemrograman Web
  • Git dan GitHub


Alur Mengikuti Coding Club

  1. Mengisi formulir pendaftaran
  2. Mengikuti pertemuan pertama
  3. Belajar dasar pemrograman
  4. Membuat proyek sederhana
  5. Presentasi hasil proyek
